SimuladorRemap

Simulador e plataforma de treino de remap automotivo em dinamômetro: ECU OEM e standalone sobre um motor termodinâmico 0D/1D que ganha potência ou quebra com laudo da causa. Local-first, um container por estação. Desde a feature 003, os kernels do tick rodam em Rust quando a extensão está instalada.

Para um novo dev

  1. Leia a feature 001 para entender o MVP e as 3 jornadas.
  2. Leia a feature 003 antes de mexer em physics, ecu ou damage: toda mudança no hot path precisa de paridade com o Rust.
  3. Veja a arquitetura: o laço sensors → ecu → physics → damage → telemetry é o coração.
  4. Consulte o glossário antes de ler as specs em _reversa_sdd/sdd/.
  5. Suba o ambiente com make dev, compile a extensão com make native (opcional) e rode make check antes de cada entrega.
